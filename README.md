
# AI Learning Roadmap Generator

An AI-powered application that generates personalized learning roadmaps using Python, Streamlit, and the Groq API.

## Features
- Choose a learning field
- Select your skill level
- Choose your learning duration
- Generate weekly learning plans
- Get project ideas and learning resources

## Technologies
- Python
- Streamlit
- Groq API

## Run Locally
Install the dependencies:

    pip install -r requirements.txt

Run the application:

    streamlit run aap.py

## API Key
Configure your Groq API key privately using Streamlit secrets.
Never publish your API key on GitHub.
